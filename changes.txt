本次实际修改 (仅 run_qwen3_0520.sh)
-----------------------------------
1) 模型路径改为本地绝对路径
   新镜像内未缓存 HuggingFace repo Qwen/Qwen3-4B，且脚本设
   HF_HUB_OFFLINE=1，原写法 "Qwen/Qwen3-4B" 会触发
   LocalEntryNotFoundError。改为：
     ACTOR_PATH="/external/InnovationLab/models/Qwen/Qwen3-4B"
   block #1 与 block #2 的默认值都改了。

2) 数据集路径硬编码到 /external/InnovationLab/data
   原脚本默认 DEV_ROOT_PATH=$HOME，把数据路径拼成
     /root/data/retool-dapo-math-scout-toolmandate/...
   该路径在容器里不存在，rank 全部抛 FileNotFoundError。改为：
     TRAIN_DATASET_PATH=/external/InnovationLab/data/retool-dapo-math-scout-toolmandate/train.parquet
     VALID_DATASET_PATH=/external/InnovationLab/data/retool-dapo-math-scout-toolmandate/test_mini128.parquet
   block #1 与 block #2 都改了。
   注意：VALID 不再回退到 TRAIN，按 verl 脚本语义指向 test_mini128。

除以上两处之外，未改动任何源代码、yaml 或其他文件。
